### Content filter investigation

Two on-topic questions returned status 400 (`content_filter`) on every run although they passed every guardrail. `diagnose_filter.py` sends each question with the full system prompt, the prompt without its internal marker line, a minimal system prompt and no system prompt, and then sends reworded versions. 9 of 14 requests were blocked. The hangboard question was blocked with every system prompt variant, including none, so its own wording triggers the filter and the system prompt is not involved. 3 of 3 reworded versions of the hangboard question passed (different wording, keeps the word hang, no hang word). The figure eight question was blocked with every system prompt variant, including none, so its own wording triggers the filter and the system prompt is not involved. 2 of 3 reworded versions of the figure eight question passed (longer wording, different knot). The provider named these filter categories: self_harm:medium.

The assistant does not retry or rephrase a message that the provider's filter blocked, because that would weaken a safety layer it does not control. It tells the user the filter blocked the message, and the cause is recorded in the log. Evidence file: `filter_diagnosis.md`.
